# q_speaker — จอเรียกคิว (Android / TV Box)

แอปแสดงจอคิวและพูดเรียกคิวด้วยเสียง (Text-to-Speech) สำหรับ Android TV Box และแท็บเล็ต

## ดาวน์โหลด

**เวอร์ชันล่าสุด:** https://github.com/tehnplk/q_speaker/releases/latest/download/q_speaker.apk

ทุกเวอร์ชัน: https://github.com/tehnplk/q_speaker/releases

## ติดตั้ง

1. ดาวน์โหลด `q_speaker.apk` ลงเครื่อง (เปิดลิงก์ด้านบนด้วยเบราว์เซอร์บน TV Box หรือคัดลอกไฟล์ผ่าน USB)
2. เปิดไฟล์ แล้วอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้แอปที่ใช้เปิดไฟล์ (เบราว์เซอร์ / ตัวจัดการไฟล์)
3. เปิดแอป **จอเรียกคิว** ครั้งแรกจะเข้าหน้า **ตั้งค่า**
   - **hoscode** / **hoskey** — รหัสโรงพยาบาลที่ได้รับ
   - **URL จอคิว** — เช่น `http://192.168.1.120/op` (ต่อท้ายด้วย `/รหัสแผนก`)
   - กด **บันทึก**

อัปเดตเวอร์ชันใหม่: ดาวน์โหลดแล้วติดตั้งทับได้เลย ค่าที่ตั้งไว้ยังอยู่

## ใช้กับรีโมท TV

- ลูกศร ขึ้น/ลง เลื่อนช่อง, OK เลือก, Back ย้อนกลับ
- ที่จอคิว กดปุ่มใดก็ได้บนรีโมท (หรือแตะจอ) ปุ่ม ⚙ จะโผล่มุมขวาล่าง กด OK อีกครั้งเพื่อเข้าหน้าตั้งค่า
- ปรับเสียงพูด (เครื่องมือ TTS, ความเร็ว, ระดับเสียง): หน้าตั้งค่า → **ตั้งค่าเสียง** (มุมขวาบน)
